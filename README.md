# MEDISIGN — 동아리 소개 사이트

간호대학 의료 접근성 봉사 동아리 **MEDISIGN**의 원페이지 소개 사이트입니다.

> 말이 닿지 않는 곳에서, 몸의 신호를 읽습니다.

## 구조

- `index.html` 파일 하나로 동작하는 정적 사이트입니다 (빌드·설치 불필요)
- 로컬에서 보기: `index.html`을 브라우저로 열면 끝
- 배포: GitHub Pages 사용 시 저장소 **Settings → Pages → Branch: `main` / root** 선택

## 수정 포인트

`index.html` 안의 `TODO` 주석을 검색하면 바꿀 곳이 나옵니다.

1. `○○대학교` → 실제 학교명 (05 About 섹션)
2. `medisign.official@gmail.com` → 실제 동아리 이메일 (07 Contact 섹션, 3곳)
3. `@medisign.official` → 실제 인스타그램 계정

활동이 하나 끝날 때마다 `06 Archive` 섹션의 형식대로 한 줄씩 추가하면 됩니다.

## 접근성

접근성을 다루는 동아리답게, 사이트도 접근성(KWCAG 기반)을 지킵니다 —
스킵 링크, 키보드 탐색, 스크린리더 레이블, 명도 대비, 움직임 줄이기 설정 지원.
수정할 때도 이 기준을 지켜 주세요.
