# MEDISIGN — 동아리 소개 사이트

간호대학 의료 접근성 봉사 동아리 **MEDISIGN**의 원페이지 소개 사이트입니다.

> 말이 닿지 않는 곳에서, 몸의 신호를 읽습니다.

## 구조

- `index.html` 파일 하나로 동작하는 정적 사이트입니다 (빌드·설치 불필요)
- 로컬에서 보기: `index.html`을 브라우저로 열면 끝
- 배포: GitHub Pages 사용 시 저장소 **Settings → Pages → Branch: `main` / root** 선택

## 수정 포인트

`index.html` 안의 `TODO` 주석을 검색하면 바꿀 곳이 나옵니다.

1. 동아리 이메일이 생기면 09 Contact 섹션과 메뉴에 mailto 링크 추가
   (현재 문의는 모두 인스타그램 `@medisign.2026`으로 연결)

### 활동 기록 추가

- **06 Archive** — 활동이 끝날 때마다 `.arc-row` 형식대로 한 줄씩 추가
- **07 Gallery** — 사진은 `assets/gallery/`에 넣고, `.empty` 칸을 `<img>`로 교체
  (교체 방법은 해당 섹션 위 주석에 예시가 있습니다)

사진의 `alt`에는 "사진"이 아니라 **무엇이 보이는지**를 적어주세요.
화면을 못 보는 사람에게 그 장면을 대신 전하는 문장입니다.

## 디자인

- 포인트 색: 밝은 배경 `#0E6E45`, 어두운 배경 `#5FD39B`
- 한글은 Pretendard(산세리프)로 통일, **라틴 문자에만** Playfair Display 이탤릭
  (`.en` 클래스 + `lang="en"`). 한글에는 절대 세리프/이탤릭을 적용하지 마세요 — 가독성이 크게 떨어집니다.
- 첫 방문 시 시작화면(인트로)이 잠깐 뜹니다. 같은 탭에서 재방문하면 뜨지 않습니다.

## 접근성

접근성을 다루는 동아리답게, 사이트도 접근성(KWCAG 기반)을 지킵니다 —
스킵 링크, 키보드 탐색, 스크린리더 레이블, 명도 대비, 움직임 줄이기 설정 지원.
수정할 때도 이 기준을 지켜 주세요.
